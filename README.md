# Архитектура RISC-V

- Номер группы - 118
- Порядковый номер - 12
- Среда разработки и моделирования - RARS 1.6
- Язык программирования: Assembly (RISC-V)

### Задание a. Проверка номера студента

Напишите программу на ассемблере RISC-V , которая принимает на вход целое число x и выводит 1, если оно соответствует номеру студента в списке группы и  0, если не совпадает

### Задание b. Вывод значений заданного диапазона

Напишите программу на ассемблере RISC-V, которая принимает на вход целое число x и выводит все значения в диапазоне min(x, y)...max(x, y) с шагом h. Где y – номер группы, h – номер студента в группе

### Задание c. Заполнение массива

Напишите программу на ассемблере RISC-V, которая заполняет массив из 16+n целых чисел значениями из стандартного ввода. Программа считывает значения в цикле и завершает чтение, когда считаны все 16+n значения или когда считано значение 0 (n – номер студента в группе)

**RARS 1.6** — симулятор архитектуры RISC-V \
**Git** — система контроля версий \
`li` — загрузка непосредственного значения в регистр \
`mv` — копирование значения между регистрами \
`add`, `addi` — арифметические операции \
`beq`, `beqz`, `bge`, `ble` — условные переходы \
`lw`, `sw` — чтение и запись данных в память \s
`ecall` — выполнение системных вызовов \
